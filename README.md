# design_pattern
这里写下我理解的design pattern的笔记和C++,python的代码。 如果有问题，欢迎指正
在学这本书前，要先了解为啥分三种类型，创建型，结构性和行为型。
这三种类型对应着不同的应用场景。 
创建型就是我们想要创建对象的时候，想要的一种设计结构。 比如创建多个复杂对象，想要让整个架构清晰，易执行（不违反反转依赖和开闭原则等基本设计原则）。
结构型是为了怎样组装现有的类，主要是对象和对象之间的结构关系，比如继承依赖，要考虑后续的可维持性和可拓展性
行为型我理解的是主要是对类和对象的动作，工作流程或者说行为的模式的描述。（也许不准确，暂时这么理解）
